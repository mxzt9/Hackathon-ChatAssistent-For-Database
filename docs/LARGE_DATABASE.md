# Большая учебная база

Отдельная PostgreSQL-база `university_large`: 240 465 записей, примерно 34 МБ.
Скрипт создаёт новую базу, сохраняя исходную `university`. Данные синтетические, seed=42, годы 2021–2026.

| Таблица | Записей |
|---|---:|
| faculties | 5 |
| programs | 20 |
| teachers | 200 |
| courses | 240 |
| students | 10 000 |
| applications | 30 000 |
| grades | 200 000 |

Связи: faculty → programs → students/applications, teacher → courses,
student + course → grades. Внешние ключи и индексы созданы, статистика обновлена.

## Подключение

В панели http://127.0.0.1:8000:

- Адрес: `127.0.0.1`
- Порт: `5432`
- База: `university_large`
- Пользователь: `assistant_ro`
- Пароль: `change_me`
- SSL: отключён

После подключения выберите таблицы и колонки, затем создайте ссылку.
Кнопка «Выбрать все доступные поля» включает разрешённые поля для этой схемы.
ФИО учащихся, контакты и паспорта закрыты также правами PostgreSQL.
Оценки и идентификаторы учащихся разрешены в агрегатах; ключи нужны для JOIN.

## Контрольные ответы

| Вопрос | Контрольный ответ PostgreSQL |
|---|---:|
| Сколько всего студентов? | 10 000 |
| Сколько всего заявлений? | 30 000 |
| Какова средняя оценка всех студентов? | 3,819805 |
| Сколько студентов поступило в 2026 году? | 1 666 |

Контрольные SQL:

```sql
SELECT COUNT(*) FROM students;
SELECT COUNT(*) FROM applications;
SELECT AVG(grade) FROM grades;
SELECT COUNT(*) FROM students WHERE admission_year = 2026;
SELECT admission_year, COUNT(*) FROM students GROUP BY admission_year ORDER BY admission_year;
```

Другие вопросы для экспериментов:

- Покажи преподавателей по математике.
- Посчитай студентов по годам поступления.
- Сколько студентов на каждой образовательной программе?
- Покажи пять программ с наибольшим количеством студентов.
- Посчитай заявления по статусам.
- Покажи среднюю оценку по каждой дисциплине.

Списки ограничены 100 строками, агрегаты считаются по всей таблице.
Модель может ошибаться: проверяйте показанный SQL и сравнивайте с контрольными запросами.

## Создать ещё одну базу

```powershell
python -m pip install -r requirements-dev.txt
python -m database.create_large_db --name university_large_2
```

Объём задаётся параметрами `--students`, `--applications`, `--grades`.
По умолчанию — 10 000 студентов, 30 000 заявлений и 200 000 оценок.
Скрипт отказывается изменять существующую БД, поэтому для повторения укажите новое имя.
