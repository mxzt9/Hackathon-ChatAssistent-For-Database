# Чат с PostgreSQL

Администратор подключает базу, выбирает таблицы и колонки и получает ссылку на чат.
SQL генерируется моделью Qwen2.5-Coder-3B-Instruct.

## Запуск

Python 3.12 и доступная PostgreSQL.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-qwen.txt
Copy-Item .env.example .env
python -m ml.qwen --download-only
python run.py
```

Откройте http://127.0.0.1:8000. Готовность модели: `/api/health`, поле `model: ready`.
Для CUDA требуется совместимая сборка PyTorch; без CUDA используется CPU.

## Подключение

Для собственной PostgreSQL укажите адрес, порт, базу, пользователя и пароль
в форме на главной странице. Используйте пользователя с правами только на чтение.
После подключения выберите колонки и создайте ссылку на чат.

При необходимости `docker compose up -d postgres` поднимает пустую PostgreSQL:
`127.0.0.1:5432`, база и пользователь `university`, пароль `university`.
Создайте свои таблицы и отдельного пользователя только для чтения.
Существующие Docker volumes сохраняются.

Подключения и ссылки чатов хранятся в памяти и сбрасываются при перезапуске сервера.

Модель составляет SQL по разрешённой схеме. Проверяются структура SELECT,
доступные колонки, ограничения агрегатов и внешние ключи.
После ошибки проверки допускается попытка исправления SQL.
Повторно отклонённый запрос не выполняется. Корректность смысла ответа
проверяется отдельно тестами с эталонными результатами.

Логи: `logs/server.log` и `logs/model.log`. Для каждого файла сохраняется одна
резервная копия, размер ограничен 2 МБ. Реквизиты подключения, вопросы и результаты
из БД в лог не записываются.

## Проверки

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
```

Полная проверка с настоящей Qwen и локальной тестовой БД университетской структуры:

```powershell
$env:TEST_QWEN_E2E = '1'
$env:TEST_DB_NAME = 'university_large'
python -m pytest tests/test_qwen_e2e.py -q
```

Подключение берётся из `DEMO_DB_*` в `.env`, имя базы переопределяется
через `TEST_DB_NAME`. Тесты только читают существующие данные и сравнивают
ответы с эталонным SQL. Перед запуском остановите сервер с Qwen, чтобы
две копии модели не занимали видеопамять. Локальный отчёт с ответами модели:
`.test-tmp/qwen-e2e.json` (исключён из Git). Обычные тесты модель не загружают.
